# QR Code Component

A responsive QR code component built as part of a Frontend Mentor challenge.

## Overview

This project is a simple QR code component that displays a QR code along with a heading and description.

The goal was to recreate the provided design as closely as possible while practicing HTML and CSS.

## What I Learned

- Structuring a webpage using semantic HTML
- Centering elements using CSS Flexbox
- Working with spacing, padding, and margins
- Creating responsive layouts
- Using CSS to match a design accurately

## Built With

- HTML5
- CSS3
